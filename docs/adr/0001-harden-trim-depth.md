# 裁剪深度：真删，且不再跟随上游

上游 LoopForge 是团队工作台，覆盖多人协作（成员账号、项目成员与加入申请、
共享任务市场、企业 IM 机器人、业务域报表、SSO 网关身份）。
MuseForge 定位为个人长期使用的轻量项目，因此这些能力**从代码里删除**，
而不是靠环境变量关掉。

**为什么真删而不是配置关闭**：只关功能的话，团队功能的代码、数据库表、
迁移脚本和前端模块全都还在 —— 镜像体积、启动时间、每次跟随上游的解冲突成本
都不会下降，与「轻量」的目标相悖。

**不再跟随上游**：MuseForge 是独立仓库，不保留上游镜像分支，
不设置 upstream remote，也不做上游同步。上游的 MIT 许可证与原始版权声明
按许可证要求保留在 `LICENSE`，其余代码与文档不再向上游回流。

**分支约定**：`dev` 承载全部个人改动，`stable` 从 `dev` 打发布。
两个分支都只属于本项目。

**代价**：不再获得上游的后续修复与新功能，需要自己维护。这换来了
「体积可控、语义清晰、只有一个使用者」的长期可维护性，是明确的取舍。
