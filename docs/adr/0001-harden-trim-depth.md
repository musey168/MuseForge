# 裁剪深度：真删，接受上游同步冲突

上游 LoopForge 是团队工作台，覆盖多人协作（成员账号、项目成员与加入申请、
共享任务市场、企业 IM 机器人、业务域报表、SSO 网关身份）。
MuseForge 定位为个人长期使用的轻量项目，因此这些能力**从代码里删除**，
而不是靠环境变量关掉。

**为什么真删而不是配置关闭**：只关功能的话，团队功能的代码、数据库表、
迁移脚本和前端模块全都还在 —— 镜像体积、启动时间、每次跟随上游的解冲突成本
都不会下降，与「轻量」的目���相悖。真删之后，`main` 保持与上游逐字一致，
所有裁剪只发生在 `dev` 分支，跟随上游时人工解冲突集中在一处。

**分支约定**：`main` 是上游的纯镜像（`scripts/sync-upstream.sh` 快进），
`dev` 承载全部个人改动，`stable` 从 `dev` 打发布。

**代价**：每次上游同步，`dev` 需要人工解决裁剪造成的冲突。这是为体积和
可维护性付出的明确成本，不是意外。
